# ReSheath coming soon site

Static site: `index.html`, `favicon.svg`, and `assets/`.

## Connect the email list (required before launch)
The signup form does not save anything until it has somewhere to send emails.
1. Create a form at a service such as Formspree.
2. Paste its URL into `SIGNUP_ENDPOINT` near the bottom of `index.html`.
3. Submit a test email and confirm it arrives.

## Hosting
Published with GitHub Pages from the `main` branch. Pushing to `main` updates the site.

## Product claims
Do not claim ReSheath certifies authenticity or replaces official mint packaging. Confirm dimensional compatibility for bars in each size before advertising universal fit.
